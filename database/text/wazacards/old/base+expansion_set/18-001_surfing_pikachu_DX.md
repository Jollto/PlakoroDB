なみのりピカチュウのプラコロ。説明書にも明記されているように、なみのりピカチュウはピカチュウのワザカードを使えるが通常のピカチュウはなみのりピカチュウのワザカードを使えないことに注意。
かといってピカチュウの技カードは実戦には耐えないため、カスタマイズする場合は拡張パック1.ピカチュウの技を使う事になるだろう。
