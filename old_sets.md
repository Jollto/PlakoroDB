# Sets

## Base Set

Under Original code number, set code with `OG`

## Expansion Set

Since they are more moves for existing Pokémon, they will use the original Pokémon number set, and set code `OX`

## Evolution Set

Under original code number, set code `OE`

## Limited Edition

set code `LE`
